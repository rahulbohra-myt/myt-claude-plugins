# Playbook — Free Event Landing Page

**Side:** Student · **Track:** B — pure conversion (`MYT_Brand_Core.md` §9)
**Status:** ⚠️ Provisional — no shipped examples in `examples/free-event-lps/` yet. At first use, ask
the user for a real event LP (doc, URL, screenshot, or Figma node). If they have none, generate and
label the output provisional.
**Default CTA:** registration verb ("Register for free" / "Save your spot") → event registration
destination (confirm URL or form) · Trust line: "Free to join"

## When this applies

A free, time-bound student event — e.g. "Yoga for Sciatica", "Yoga for Back Pain" live sessions,
challenges, or themed community classes.

## Category intake (on top of the shared intake)

1. Event name and topic
2. Date, time, timezone, duration; one session or a series
3. Format: live via Zoom? Replay available?
4. Host teacher(s) — name, credentials, photo available?
5. Seats or registration deadline (only if real — never invent scarcity)
6. What attendees walk away with
7. Registration destination and what happens after registering (e.g. free-session offer)
8. Does the hero use the same name + WhatsApp form as paid LPs, or a different registration form?
9. Past attendee testimonials available?

Section names refer to `LP_Section_Library.md`.

## Tone

Warm, with a genuine urgency/community layer (Brand Core §4). Urgency must be true — a real date or
real seat limit.

## Category rules

- State "free" clearly in the hero and the Event Details Card.
- Condition topics (sciatica, back pain) trigger the medical disclaimer (Brand Core §6).
- Brand Core terminology and figures apply as on every page.

## Optional add-ons

- Meta ad angles: announcement, outcome, past-attendee proof, date/seat urgency
- Email: 3 subject lines (benefit, urgency, social proof)
- Page meta + Event schema (once date/time are confirmed)
