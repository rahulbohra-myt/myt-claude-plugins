# Playbook — Paid Ad Landing Page (Meta / Google)

**Side:** Student · **Track:** B — pure conversion (`MYT_Brand_Core.md` §9)
**Status:** Calibrated — shipped copy in `examples/paid-lps/` plus Figma pages (Prenatal, Hormonal
Balance, Back Pain) and a live production hero screenshot.
**Default CTA:** "Book a free session" → free-session booking / onboarding (confirm destination URL)
· Trust line: "No Credit Card Required"

## When this applies

A student-facing page that paid Meta or Google traffic lands on. Page types:

| LP type | Examples |
|---|---|
| Condition-led | sciatica, back pain, neck & shoulder, postpartum, hormonal health |
| Audience-specific | desk workers, seniors, beginners, new moms |
| Lifestyle | stress relief, sleep, energy, flexibility |
| Yoga style | yin, hatha, vinyasa |

## Category intake (on top of the shared intake)

1. LP type (table above) and the topic
2. Channel: Meta, Google, or both
3. **Message match:** the ad headline / primary text driving traffic — the H1 must mirror its promise
4. Primary pain point or goal of the audience
5. Real student testimonials and teacher profiles available? (yes / no / partial)
6. Strong media for the hero (video or live-session image)? → decides Hero Option A vs B
7. Does the topic split into distinct sub-needs? → decides Benefits Grid Section
8. Comparison frame — propose the default below, confirm

## Section recipe

Section names refer to `LP_Section_Library.md`.

| # | Section | Include | Category notes |
|---|---|---|---|
| 1 | Hero Section | Always | Option A (Combined Funnel Header with name + WhatsApp form) by default; Option B (Media Hero) only when a strong media asset exists |
| 2 | Logo Mark | Always | Press logos |
| 3 | Benefits Grid Section | Conditional | Broad topics with sub-needs (e.g. hormonal health) |
| 4 | Benefit Section | Always | Framing per type table below |
| 5 | How It Works | Always | 3 steps |
| 6 | Text Testimonials | Always | Real quotes first; placeholders clearly marked |
| 7 | Expert Teachers | Always | Specializations relevant to the topic |
| 8 | Comparison Table | Always | Frame + rows 3–4 per type table below |
| 9 | Video Testimonials | Always | Topic-relevant stories |
| 10 | FAQ Section | Always | Disclaimer when condition-led |
| 11 | Landing CTA | Always | Same CTA verb as the hero |

Optional components (offer, don't force): Use Cases, Testimonials — Alternate Format, For Your Unique Needs.

## Tone & framing by LP type

| LP type | Benefit Section framing | Tone | Comparison frame default | Comparison rows 3–4 | Disclaimer |
|---|---|---|---|---|---|
| Condition-led | Empathy first — name the sensation, not the solution | Warm, validating, safe | YouTube / Generic Videos (prenatal/postnatal: Traditional In-Person Classes) | Safety + pain-trigger awareness | Required (Brand Core §6 short form) |
| Audience-specific | Identity first ("for you, as a…") | Inclusive, relatable | YouTube / Generic Videos | Life-stage adaptation + scheduling fit | Situational |
| Lifestyle | Aspiration + relief | Uplifting, practical | YouTube / Apps | Consistency + progression | Not required |
| Yoga style | Depth + progression | Encouraging, knowledge-led | Generic Online Videos | Progression/depth + teacher expertise | Not required |

## Category rules

- One promise, one CTA, repeated identically (Brand Core §3.1 microcopy).
- Never mention price.
- No keyword-density constraint (Track B) — write for the reader who clicked the ad.
- Platform figures come from Brand Core §8; confirm they're current.
- The shipped examples predate current rules — they use "instructor", "Coaching", "Real", and
  "Book Your Free Session", and their hero docs lack the lead form. Where examples conflict with
  Brand Core or the library, Brand Core and the library win.

## Optional add-ons (offer after the copy is approved)

- **Meta ads:** 4 angles — pain/problem recognition, failed solutions, safety/objection, transformation
- **Google ads:** responsive search ad headlines (≤30 characters each) and descriptions (≤90
  characters each); keyword shortlist via Ahrefs if the user wants one
- **Page meta:** meta title (~60 chars), meta description (~155 chars), FAQ schema
- **Image brief:** desktop hero 1550×1004px, mobile hero 375×496px; mood-led description, no text in image
