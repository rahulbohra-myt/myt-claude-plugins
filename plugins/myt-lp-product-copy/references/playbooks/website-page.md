# Playbook — Website Pages (Home, Services, Product, About, Contact)

**Side:** Mostly student
**Track:** A — SEO-blended (`MYT_Brand_Core.md` §9): rank organically *and* convert. The primary
keyword belongs in the title, meta, and H1; header hierarchy matters.
**Status:** ⚠️ Provisional — no shipped examples in `examples/website-pages/` yet. Before the first
generation of each page type, ask for the live page URL or existing copy.
**Default CTA:** "Book a free session" · Trust line: "No Credit Card Required" (Brand Core §3.1),
unless the page's goal is different (e.g. Contact).

## Category intake (on top of the shared intake)

1. Page type: home / services / product / about / contact / other
2. New page or a rewrite? If a rewrite, the live URL
3. Primary keyword (and secondary keywords) — or run keyword research (Ahrefs) first?
4. Page goal and primary CTA
5. Must-include facts (offer details, policies, locations, support hours)

## Section recipes

Section names refer to `LP_Section_Library.md`.

### Home page (provisional — confirm against the live homepage)
Brand Core §9.1 names the homepage as the Track A model: keyworded H1 plus the full conversion
toolkit.

Hero Section (Option A — Combined Funnel Header; the homepage starts Combined Funnel Onboarding) →
Logo Mark → Benefit Section → How It Works → Text Testimonials → Expert Teachers → Comparison Table →
Video Testimonials → FAQ Section → Landing CTA

### Services / product page (provisional — e.g. 1-on-1 sessions, group classes)
Hero Section → Logo Mark → Benefit Section → [Benefits Grid Section] → How It Works → Expert
Teachers → Text Testimonials → [Comparison Table, if a competitor frame exists] → FAQ Section →
Landing CTA

### About Us — ⛔ blocked on an example
Likely needs components the library doesn't have yet (mission/story, founders/team, values, scale
figures). Collect the live page or a reference first, add the components to `LP_Section_Library.md`
with a cited source, then define the recipe here.

### Contact Us — ⛔ blocked on an example
Likely needs components the library doesn't have yet (contact options, support hours, form). Same
process as About Us.

## Category rules

- Keyword in H1, meta title, and at least one H2 — naturally, never stuffed.
- Figures from Brand Core §8; confirm they're current.
- Condition-related service pages trigger the medical disclaimer (Brand Core §6).

## SEO add-ons (default on for this category)

- Meta title (~60 chars) and meta description (~155 chars)
- H1/H2 keyword placement notes
- Schema suggestions (Organization, FAQ, Service)
- Internal link suggestions
