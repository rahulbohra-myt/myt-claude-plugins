# Examples — Real Shipped Copy

Calibration material for `myt-page-copy`. Only real, shipped (or approved-for-ship) copy belongs
here — never generated drafts.

| Folder | Category | Status |
|---|---|---|
| `paid-lps/` | Paid ad LPs (Meta / Google) | 5 pages |
| `teacher-hiring-lps/` | Teacher hiring LPs | 1 page — more specializations wanted |
| `free-event-lps/` | Free event LPs | 1 page — quarterly main event wanted |
| `workshop-lps/` | Workshop LPs (free, paid, nutrition, TTC) | Empty — needed |
| `website-pages/` | Home, services, product, about, contact | Empty — needed |

**Adding an example:** one markdown file per page, named `<topic>-<category>.md`. Start with the
live URL, then the copy section by section. Keep the copy as shipped — don't fix it.

**Older examples predate current rules.** Several use "instructor", "Coaching", "Real", or "Book
Your Free Session", and paid-LP docs lack the hero's name + WhatsApp form. Where an example
conflicts with `MYT_Brand_Core.md` or `LP_Section_Library.md`, those files win.
